# Estruturas de Decisão em JavaScript

As estruturas de decisão permitem que um programa execute diferentes blocos de código com base em uma condição. Em JavaScript, as principais são:

- **`if`**: executa um bloco se a condição for verdadeira.
- **`if...else`**: define um caminho alternativo quando a condição é falsa.
- **`else if`**: permite testar múltiplas condições em sequência.
- **`switch`**: ideal para comparar uma mesma variável com vários valores possíveis.

Essas estruturas utilizam expressões booleanas (`true` ou `false`) e operadores de comparação (`==`, `===`, `!=`, `>`, `<`, `>=`, `<=`) e lógicos (`&&`, `||`, `!`) para controlar o fluxo da aplicação.
