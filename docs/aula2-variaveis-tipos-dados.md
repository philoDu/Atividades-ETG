Variáveis são palavras para guardar dados na memória do código, elas podem ser mutáveis dinamiacamente, declaradas com 'let', ou imutáveis em seu conteúdo, declaradas com o 'const'.
Os tipos de dados primitivos em JavaScript são:

String - dados textuais, como "Olá, mundo!";
Number - dados numéricos inteiro e decimais, como 3 ou 45,78;
BigInt - números inteiros acima do limite de Number;
Boolean - true ou false, apenas;
Undefined - valor padrão de variáveis declaradas mas que não receberam dados;
Null - palavra reservada para a ausência intencional de valor;
Symbol - um identificador único e imutável.

Em JS, o operador 'typeof' retorna o tipo da variável:
typeof "Olá, mundo!" // "string"
typeof 3 // "number"
