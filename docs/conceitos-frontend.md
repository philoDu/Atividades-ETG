# Frontend (Client-side)

O **Frontend**, também chamado de **Client-side**, é a camada da aplicação com a qual o usuário interage diretamente. Ele corresponde à interface gráfica do sistema, incluindo botões, menus, formulários, textos, imagens e demais elementos visuais apresentados no navegador.

No desenvolvimento web, o Frontend é construído principalmente com três tecnologias:

- **HTML**: define a estrutura e o conteúdo da página.
- **CSS**: controla a aparência, o layout e a estilização dos elementos.
- **JavaScript**: adiciona interatividade e dinamismo à interface, respondendo às ações do usuário.

## Bibliotecas e Frameworks

Para facilitar o desenvolvimento de interfaces modernas, existem diversas bibliotecas e frameworks JavaScript. Entre os mais utilizados estão:

- **React**: biblioteca voltada para a criação de interfaces baseadas em componentes.
- **Vue.js**: framework progressivo conhecido pela simplicidade e facilidade de aprendizado.
- **Svelte**: framework que gera código altamente otimizado durante a compilação.
- **jQuery**: biblioteca que simplifica a manipulação do DOM e eventos, muito utilizada em projetos legados.

## Objetivo do Frontend

O principal objetivo do Frontend é oferecer uma interface intuitiva, responsiva e agradável ao usuário, garantindo uma boa experiência de navegação e comunicação com o Backend da aplicação.
