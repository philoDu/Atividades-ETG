---FRONTEND---

Frontend ou client side é o lado gráfico da aplicação, com o qual o usuário interage. Portanto é a 'cara' do sistema, seus botões, textos, inputs e outputs que o usuário vê.
No mundo do desenvolvimento web, o frontend começa com HTML e CSS, tendo também uma boa dose de código JavaScript fazendo rodar as interface gráficas.
Existem bibliotecas próprias para desenvolver frontend na web, as mais comuns são: React, VueJS, Svelte e JQuery.
