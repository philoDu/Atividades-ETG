# Páginas Estáticas

Uma **página estática** é uma página web cujo conteúdo é previamente definido e enviado ao navegador exatamente como foi criado. Seu conteúdo não muda automaticamente de acordo com o usuário ou com dados armazenados em bancos de dados.

Normalmente, páginas estáticas são desenvolvidas utilizando **HTML** para a estrutura, **CSS** para a aparência e **JavaScript** para adicionar interatividade no lado do cliente.

## Características

- Conteúdo fixo e previamente definido.
- Carregamento rápido e baixo consumo de recursos.
- Fácil hospedagem em serviços como GitHub Pages.
- Ideal para portfólios, páginas institucionais, documentações e sites informativos.

## Vantagens

- Maior desempenho.
- Maior segurança, pois não depende de processamento no servidor.
- Simplicidade de desenvolvimento e manutenção.
- Menor custo de hospedagem.

## Limitações

- Alterações no conteúdo exigem edição dos arquivos e nova publicação.
- Não possui funcionalidades dinâmicas nativas, como autenticação, cadastro de usuários ou integração com banco de dados, sem o uso de serviços externos ou APIs.

As páginas estáticas são uma excelente opção para projetos simples e para o aprendizado dos fundamentos do desenvolvimento web, servindo como base para aplicações mais complexas.
